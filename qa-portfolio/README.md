## About the material in this folder

The files in this folder are retained as a supplementary, practice-oriented QA case study created around the Green Fitness demonstration app. They are not the primary portfolio and should not be used as the lead project in current job applications.

**Evidence status:** the 26 listed test cases are designed test cases and are marked `Not Run`. The sample defect examples are hypothetical exercises, not observed production defects. The documentation validator checks test-case structure; it does not execute the application.

For the current profile, use the Match Signal portfolio link above.
