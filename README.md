# Green Fitness Performance Club

Mobile-first demo for Green Fitness, Ikotun, Lagos.

## Run
Open `index.html` in a modern browser. No build step or paid service is required.

## Demo roles
- Member: digital membership card, simulated check-in, workout and progress.
- Trainer: roster, routine builder and trainer notes.
- Owner: attendance, renewals and illustrative finance dashboard.
- Wellness: meal logging and simulated wearable telemetry.

All people, financial figures and telemetry in this demo are fictional. QR check-in and wearable data are simulations, not live integrations. This prototype uses browser local storage and is not ready for real member records or payments. Production requires secure authentication, role-based server permissions, database, consent, audit logs, backups and verified payment webhooks.
